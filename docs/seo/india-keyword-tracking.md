# India Keyword Tracking

**No baseline positions are recorded here.** No rank tracker or Search Console data was available during this project, and positions must not be estimated. The owner should fill in the baseline after connecting Google Search Console (property: https://www.zspace.in), filtered to **Country: India**.

## How to track

1. Search Console → Performance → Search results → filter Country = India.
2. For each keyword below, record impressions, clicks, average position and the ranking URL, monthly.
3. If the ranking URL differs from the target URL, check internal links and titles before creating anything new (avoid cannibalisation).
4. Optional: a rank tracker set to google.co.in, English, desktop and mobile.
